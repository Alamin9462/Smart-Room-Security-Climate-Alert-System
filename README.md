# 🔐 Smart Room Security & Climate Alert System

An Arduino-based smart room monitoring and alert system designed to improve **room security and environmental awareness**. The system detects motion, monitors temperature and humidity, and provides alerts through LEDs and a buzzer.

This project is developed and simulated using **Wokwi**.

## 📌 Features

* 🚨 Motion detection for room security
* 🌡️ Temperature monitoring
* 💧 Humidity monitoring
* 🔔 Buzzer-based security alerts
* 💡 LED status indicators
* 📊 Serial Monitor for real-time sensor data
* ⚡ Automatic response based on sensor conditions
* 🧪 Fully simulated using Wokwi

## 🔄 How It Works

1. The Arduino initializes all sensors and output devices.
2. PIR sensors continuously monitor the room for movement.
3. When motion is detected, the corresponding LED is activated.
4. The system can trigger the buzzer when a security condition occurs.
5. Temperature and humidity data are continuously monitored.
6. Sensor readings are displayed through the Serial Monitor.
7. The system responds automatically according to the configured conditions.
